Our Story

PureShop is a demo e-commerce website built to showcase a clean, scalable architecture using only HTML, CSS, and JavaScript. No React, no Vue, no Node.js, no npm — just the web platform itself.

This project demonstrates long-term patterns you can grow with: Web Components for reusability, ES Modules for code organization, a pub/sub store for state management, and CSS custom properties for theming.

Why Vanilla?

Frameworks come and go, but HTML, CSS, and JavaScript are web standards that will be supported for decades. Learning to build without dependencies makes you a stronger developer and gives you zero build-step overhead.
